## Jira 短评

压缩为：

1. **结论**：一行说明根因与当前状态。
2. **关键证据**：2～4 条可复算的数据。
3. **影响范围**：哪些页面/算法/记录受影响，哪些不受影响。
4. **建议**：修复层与最小回归集。

不要在短评中堆完整调用链；长证据放附件或飞书报告。
